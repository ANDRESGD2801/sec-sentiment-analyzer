Cómo funciona
Dos métodos complementarios para analizar el sentimiento financiero.
📂

Parseo de archivos

Soporta PDF (PyMuPDF), TXT y HTML. Detecta secciones 10-K/10-Q: Item 1, 1A, 7, 7A, 8, etc.

📊

Logit-based

Compara logits del siguiente token para "positive", "negative" y "neutral". Analiza por chunks y promedia scores.

🤖

Instruct model

Usa el chat template de Qwen2-Instruct con un prompt de analista financiero. Devuelve etiqueta + explicación.

🔒

100% local

El modelo corre en tu máquina. Los pesos se descargan una vez desde Hugging Face (~1 GB).

Instalación
Requiere Python 3.10+ y ~1 GB de espacio en disco.
Terminal
# 1. Clona el repo
git clone https://github.com/ANDRESGD2801/sec-sentiment-analyzer
cd sec-sentiment-analyzer

# 2. Entorno virtual + dependencias
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # Mac / Linux
pip install -r requirements.txt

# 3. Lanza la app → abre http://127.0.0.1:7860
python app.py
