Cómo funciona
Dos métodos complementarios, igual que en el notebook de referencia del curso.
📂

Parseo de archivos

Soporta PDF (vía PyMuPDF), TXT y HTML. Detecta automáticamente las secciones del filing: Item 1, Item 1A, Item 7 (MD&A), Item 8, etc.

📊

Logit-based (notebook)

Compara los logits del siguiente token para las palabras "positive", "negative" y "neutral". Analiza el texto en chunks y promedia los scores.

🤖

Instruct model

Usa el chat template de Qwen2-Instruct con un system prompt de analista financiero. Devuelve una etiqueta estructurada + explicación.

🔒

100% local

El modelo corre en tu máquina. Ningún dato sale a APIs externas. Los pesos se descargan una sola vez desde Hugging Face (~1 GB).

Instalación y uso
Requiere Python 3.10+ y ~1 GB de espacio en disco.
PowerShell / Terminal 
# 1. Clona el repositorio
git clone https://github.com/ANDRESGD2801/sec-sentiment-analyzer
cd sec-sentiment-analyzer

# 2. Crea entorno virtual e instala dependencias
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Mac / Linux
pip install -r requirements.txt

# 3. Lanza la app
python app.py
